# Instructor reference solutions

This directory contains completed versions of all five activities and their
shaders. It is intentionally separate from the student-facing `exercises/`
and `shaders/` directories. Students should attempt the corresponding guide
and TODO scaffold before consulting these files.

When running a reference exercise from the repository root, use the matching
header from `reference-solutions/exercises/`. The reference headers explicitly
load shaders from `reference-solutions/shaders/`; do not replace only the
header while continuing to use the student shader paths.
